# Tabby SFTP+

**Двухпанельный SFTP-менеджер для [Tabby](https://github.com/Eugeny/tabby) — в стиле WinSCP / MobaXterm, прямо внутри терминала.**

Штатная SFTP-панель Tabby — это одноколоночный список, который выезжает поверх
терминала. **SFTP+** заменяет её полноценным двухпанельным файловым менеджером:
локальная машина слева, удалённый хост справа, drag-and-drop между ними, живая
очередь передач, встроенный редактор и отсоединяемое always-on-top окно со
вкладками — чтобы работать с файлами сразу на нескольких серверах, не выходя из Tabby.

## Зачем

- Встроенная SFTP-шторка показывает только удалённую сторону и перекрывает терминал.
- Копирование локально ⇄ удалённо превращается в борьбу с системными диалогами.
- Нет очереди передач, нет паузы/возобновления, нет правки файла без выгрузки на диск.

SFTP+ решает всё это и переиспользует **ту же живую SSH-сессию**, к которой уже
подключён твой терминал — без повторного входа и без запроса пароля.

## Возможности

### Двухпанельный обзор
- **Две панели** — локальная ФС ⇄ удалённый хост, бок о бок.
- **Сортируемые колонки** — Имя / Изменён / Размер, папки всегда сверху.
- **Фильтр по имени** — <kbd>Ctrl</kbd>+<kbd>F</kbd> в панели, фильтрует по мере ввода.
- **История навигации** — кнопки назад / вперёд / вверх для каждой панели.
- **Закладки** — отметь любую папку звёздочкой; закладки сохраняются между сессиями.

### Передачи
- **Прямая загрузка / скачивание** — двойной клик или кнопки-стрелки, без системных диалогов.
- **Drag-and-drop** — между панелями или на папку, чтобы положить *внутрь*. Рекурсивные папки поддерживаются.
- **Перемещение внутри стороны** — перетащи на папку (или на кнопку ▲ Вверх).
- **Очередь передач** — живые прогресс-бары, проценты и **пауза / возобновление / отмена** по каждому пункту.
- **Ограниченный параллелизм** — несколько передач одновременно, остальные в очереди.
- **Подтверждение перезаписи** — спрашивает перед заменой существующего файла.

### Редактирование — без временных файлов
- **Встроенный редактор** — правый клик по файлу → *Edit*, открывает файл во встроенном редакторе (и локальный, и удалённый).
- **Подсветка синтаксиса** — лёгкая, без внешних зависимостей.
- **Сохранение по <kbd>Ctrl</kbd>+<kbd>S</kbd>** — удалённая запись атомарна; точка-индикатор помечает несохранённые изменения.

### Контекстное меню
- Новая папка, переименование, удаление (рекурсивно) — на обеих панелях.
- **Показать в Проводнике** и **Открыть в приложении по умолчанию** для локальных объектов.

### Окна
- **Открыть вкладкой** внутри Tabby **или** отдельным **отсоединяемым always-on-top окном**.
- **Безрамочный титлбар в стиле Tabby**.
- **Несколько серверов в одном окне** — каждый открытый SFTP+ становится **вкладкой**
  в том же окне; открытие уже открытого сервера просто переключает на его вкладку.
- Полностью **учитывает тему** (адаптируется к светлым и тёмным темам Tabby).

## Установка и запуск

SFTP+ поставляется как **встроенный плагин внутри этого форка Tabby**. Собери форк
и запусти как обычный Tabby — плагин уже зарегистрирован.

```bash
# из корня репозитория
yarn install      # ставит зависимости (собирает нативные модули)
yarn build        # компилирует Tabby + все встроенные плагины, включая SFTP+
yarn start        # запускает Tabby в dev-режиме
```

> **Нативные модули / Windows:** для сборки всего приложения нужен тот же
> инструментарий, что и для оригинального Tabby (Node, Yarn и C++-тулчейн для
> нативных модулей). Если ловишь ошибки нативных модулей — смотри
> [руководство по сборке Tabby](https://github.com/Eugeny/tabby#building).

Чтобы дорабатывать только плагин, пока Tabby запущен, пересобери его бандл и
перезагрузи рендерер через <kbd>Ctrl</kbd>+<kbd>R</kbd>:

```bash
cd tabby-sftp-plus
yarn build
```

## Использование

1. Открой вкладку **SSH** и подключись к хосту.
2. Нажми кнопку **SFTP+** на панели инструментов.
   - **Левый клик** → открывает плавающее окно.
   - **Подменю** → выбери *Open as floating window* или *Open as tab*.
3. Просматривай, передавай, редактируй. Открой SFTP+ на других SSH-вкладках, чтобы
   добавить новые **вкладки** в то же окно.

**Полезные клавиши**

| Клавиша | Действие |
|---------|----------|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Фильтр активной панели по имени |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Сохранить во встроенном редакторе |
| Двойной клик | Войти в папку / передать файл |
| Перетаскивание | Передача между панелями или перемещение внутри панели |

## Как это устроено

SFTP+ — это плагин поверх **публичного API `tabby-ssh`**
(`SSHSession.openSFTP()` → `SFTPSession`), поэтому вся логика обзора файлов живёт
в плагине и переиспользует твою существующую SSH-сессию.

Отсоединяемое окно — это настоящее always-on-top окно ОС, которое **разделяет
JS-контекст рендерера**, поэтому *та же* живая SFTP-сессия переиспользуется без
IPC-прокси. Так как плагин не может менять main-процесс, этот форк несёт два
небольших изменения ядра:

| Файл | Изменение | Для чего |
|------|-----------|----------|
| `scripts/vars.mjs` | регистрирует `tabby-sftp-plus` как встроенный плагин | сборка плагина |
| `app/lib/window.ts` | разрешает popup SFTP+ в `setWindowOpenHandler` и делает его безрамочным (`frame: false`) | отсоединяемое окно + свой титлбар |

Всё остальное содержится в папке плагина `tabby-sftp-plus/`. Если нужен только
режим **вкладки**, плагин работает и без правки `window.ts` (теряется лишь
отсоединяемое окно).
