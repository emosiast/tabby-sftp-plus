# Screenshots

Drop the demo images here, using these exact filenames (they're referenced from
the project READMEs):

| Filename | What to capture |
|----------|-----------------|
| `hero.png` | Hero shot — the floating window, dual pane, local left / remote right |
| `dual-pane.png` | Both panes populated with files |
| `tabs.png` | The floating window with 2+ tabs in the title bar |
| `transfers.png` | The transfer queue mid-transfer (progress bars + pause/cancel) |
| `editor.png` | The in-app editor open on a remote file |
| `context-menu.png` | The right-click context menu open over a file/folder |

PNG recommended. Keep them reasonably sized (≈1200px wide is plenty).
